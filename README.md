# CertiChain — Blockchain Certificate Verification System

A full stack decentralized certificate verification system using Blockchain, IPFS, and AI/ML.

## Tech Stack
- **Frontend:** React.js, CSS
- **Backend:** Node.js, Express.js
- **Database:** MySQL (XAMPP/MariaDB)
- **Blockchain:** Solidity, Polygon Mumbai Testnet
- **Storage:** IPFS (Pinata)
- **AI/ML:** Python, Flask, scikit-learn

## Features
- University can issue blockchain-verified certificates
- Students can view, download and share certificates with QR code
- HR can instantly verify certificates on blockchain
- Email notifications via Nodemailer
- Password reset system
- AI-based fraud detection

## How to Run Locally
1. Start XAMPP (Apache + MySQL)
2. `cd backend && node server.js`
3. `cd frontend && npm start`
4. Open `http://localhost:3000`
